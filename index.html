03
Capstone project

HW Dental — marketing analytics for a growing dental chain

01
Problem
HW Dental operates four Columbus-area branches with 4,500+ new patients per year but lacks insight into which marketing channels drive acquisition — especially among Medicaid-enrolled and Spanish-speaking patients, their two primary target populations.
02
Data journey
Worked with a real, messy 21-variable dataset: inconsistent city capitalization, non-standardized referral strings (e.g., "google" vs "Internet (Google)"), an unreliable gender field, and no explicit Medicaid flag — requiring derivation from raw insurance carrier names.
03
Solution
Built a Medicaid indicator by fuzzy-matching carrier names against a reference list. Standardized referral strings using Python regex. Used cross-tabulations and segmented bar charts to compare channel performance across branches and population segments.
04
Impact
Found that Spanish-speaking patients (24% of all patients, identified via Spanish_Likelihood flag) arrive primarily via personal referral — not digital — revealing an untapped opportunity for Spanish-language digital outreach at key branches.
◆

Google dominates, but unevenly

Google is the top referral source overall, but its share varies by branch — Polaris and Westerville skew digital while Clintonville shows a higher share of personal referrals and word-of-mouth.

◆

Medicaid patients underrepresented digitally

Patients on Medicaid-associated plans arrive more often via insurance-site referrals or personal referrals than via Google, suggesting current digital spend may not efficiently reach this high-priority segment.

◆

Spanish-speaking patients rely on word-of-mouth

High Spanish Likelihood patients show a much higher personal-referral rate and lower digital capture — pointing to a clear gap in Spanish-language online advertising at Westerville and Sawmill branches.

Business recommendation

HW Dental should launch branch-specific Spanish-language Google and Meta ad campaigns, prioritizing Westerville and Sawmill. Pair this with a referral incentive program targeting existing Spanish-speaking patients to amplify the word-of-mouth channel that already works. For Medicaid reach, optimize insurance-directory listings on CareSource, Buckeye, and Molina platforms before increasing broad digital spend.

Medicaid flag derivation — SQL SQL
-- Build Medicaid indicator from raw carrier names WITH medicaid_carriers AS ( SELECT carrier_name FROM reference.medicaid_carrier_list ), patient_flags AS ( SELECT p.GlobalPatientID, p.Branch, p.InsuranceCarriers, CASE WHEN EXISTS ( SELECT 1 FROM medicaid_carriers mc WHERE LOWER(p.InsuranceCarriers) LIKE '%' || LOWER(mc.carrier_name) || '%' ) THEN 1 ELSE 0 END AS is_medicaid FROM patients p WHERE p.HasInsurance = 1 ) SELECT Branch, COUNT(*) AS total_patients, SUM(is_medicaid) AS medicaid_patients, ROUND(100.0 * SUM(is_medicaid) / COUNT(*), 1) AS pct_medicaid FROM patient_flags GROUP BY Branch ORDER BY pct_medicaid DESC;
Referral string normalization — Python Python / pandas
import pandas as pd import re # Normalize HowDidYouHear to clean categories def normalize_referral(raw): if pd.isna(raw): return 'No referral' s = raw.strip().lower() if re.search(r'google|internet', s): return 'Google / digital' if re.search(r'insurance|caresource|buckeye|molina', s): return 'Insurance site' if re.search(r'personal referral|friend|family', s): return 'Personal / word-of-mouth' return 'Other' df['referral_clean'] = df['HowDidYouHear'].apply( normalize_referral ) # Cross-tab: channel x Spanish likelihood ct = pd.crosstab( df['referral_clean'], df['Spanish_Likelihood'], normalize='columns' ).round(3) * 100 print(ct)
